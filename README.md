# NOVA - AI Assistant

## Setup

1. Go to https://console.groq.com/keys → Sign up → Get API Key (starts with `gsk_`)
2. (Optional) Go to https://build.nvidia.com → Sign up → Get API Key (starts with `nvapi-`)
3. Sign up on the website → Enter keys
4. Done!

## Features
- Chat with your own Groq key
- Image generation with your own NVIDIA key
- Each user has their own account with their own keys
